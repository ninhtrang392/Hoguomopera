# Hồ Gươm Opera

Trang giới thiệu nhà hát theo mẫu thiết kế, với giao diện Việt–Anh, bộ lọc chương trình, cửa sổ thông tin, điểm khám phá khán phòng và bố cục thích ứng trên di động.

## Chạy trên máy

Yêu cầu Node.js. Chạy `npm run dev`, sau đó mở `http://127.0.0.1:3000`.

Trang tĩnh nằm trong `dist/`, không cần cài thư viện hay biên dịch. Chạy `npm run check` để kiểm tra cú pháp JavaScript.

## Nội dung

- `dist/index.html`: bố cục và nội dung mặc định.
- `dist/styles.css`: giao diện desktop và mobile.
- `dist/app.js`: bản dịch, bộ lọc, menu, hộp thoại và điểm khám phá.
- `dist/assets/`: ảnh minh họa tạo bằng AI, không phải tư liệu chính thức của nhà hát.

Các chương trình hiện là nội dung minh họa. Chưa kết nối lịch diễn, sơ đồ ghế, hệ thống thanh toán hay bán vé thật. Khán phòng là ảnh mô hình có điểm tương tác, không phải mô hình 3D xoay được. Thay thông tin và ảnh minh họa bằng dữ liệu chính thức trước khi dùng làm website chính thức.
